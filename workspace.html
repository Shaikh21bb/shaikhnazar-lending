Три шага к своей базе.

  1. 1
    Подготовьте Mac

    Откройте вашу базу в Obsidian. Для AI-обработки запустите локальную модель Ollama; платный API не нужен.

  2. 2
    Свяжите с кабинетом

    Нажмите «Подключить мой Mac» и выполните команду в папке проекта на этом компьютере.

  3. 3
    Оставьте помощника включённым

    Пока Mac бодрствует, агент обрабатывает мысли и WhatsApp. При выключении новые мысли ждут в зашифрованной очереди.

Команда привязки

Запустите в Терминале из папки проекта. Код одноразовый; не передавайте его другим людям.
